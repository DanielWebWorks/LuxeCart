# LuxeCart — Modern E-commerce Storefront

LuxeCart is a responsive e-commerce storefront built to demonstrate modern frontend development skills. It features a clean, premium design, product browsing, shopping cart interactions, wishlist functionality, and a streamlined checkout experience.

## Features

- Responsive homepage and product catalog
- Product search, category filters, and sorting
- Product detail pages
- Shopping cart with quantity and pricing calculations
- Wishlist with saved products
- Demo checkout with order summary
- Login and signup demo forms
- Account profile and wishlist management
- Contact form with confirmation feedback
- Mobile-friendly navigation and layouts
- Browser storage using `localStorage`

## Pages

- `index.html` — Homepage
- `products.html` — Product catalog
- `product.html` — Product details
- `cart.html` — Shopping cart
- `checkout.html` — Checkout
- `login.html` — Sign-in demo
- `signup.html` — Registration demo
- `account.html` — Account and wishlist
- `contact.html` — Contact form

## Technologies Used

- HTML5
- CSS3
- Vanilla JavaScript
- Browser `localStorage`

## How to Run

1. Download or clone the project.
2. Open the project folder.
3. Open `index.html` in a web browser.

No backend setup or package installation is required.

## Demo Limitations

LuxeCart is a frontend portfolio project. Login, registration, contact, and checkout are demonstrations only. It does not create real user accounts, send messages to a support team, or process payments.

## Project Goal

Built to showcase responsive layouts, reusable interface patterns, DOM manipulation, client-side state management, and interactive e-commerce user experiences.
